# Asynchronous Activity 1: Student Early Warning Tool Using KNIME

This repository contains the required output for Asynchronous Activity 1. The project uses KNIME to predict student risk status from academic performance data.

## Files
- `Vergara-Justin-Machine-Problem-1.knwf` - The exported KNIME workflow that shows the nodes, algorithms, and scores.
- `Vergara-Justin-Machine-Problem-1.pdf` - The PDF file that shows the proof of each workflow.
- `student_performance_knime.csv` - The dataset used by the workflow.

## Algorithms
- Decision Tree
- Logistic Regression
- Random Forest

## How to Run
1. Import the `Vergara-Justin-Machine-Problem-1.knwf` file into KNIME Analytics Platform.
2. Configure the CSV Reader and select the included dataset.
3. Execute all nodes.
4. Open the Scorer nodes to review the evaluation results.
